# Морской бой чата

Бесплатная картинка-игра для стрима: каждый зритель, который пишет в чат Twitch,
получает свой кораблик на полосе моря внизу кадра. Командами в чате корабли
стреляют, уходят от огня, чинятся и ставят щиты, а последний уцелевший побеждает
раунд. Ничего платного, без входа в Twitch, без серверов и без установки — только
страница в браузере OBS.

Лицензия MIT, автор Sasha AI. Работает и с GitHub Pages, и просто как локальный
файл: все картинки и звуки рисуются кодом, из сети берётся только чат Twitch.

## Готовые страницы — ничего скачивать не нужно

* Конструктор ссылки: **https://andreyshapira1983-sketch.github.io/sea-battle-chat/builder.html**
* Посмотреть игру без чата: https://andreyshapira1983-sketch.github.io/sea-battle-chat/index.html?demo=1
* «Светлячки» и бой в одном источнике (демо): https://andreyshapira1983-sketch.github.io/sea-battle-chat/stage.html?demo=1

Откройте конструктор, впишите свой канал, скопируйте ссылку и вставьте её в OBS
источником «Браузер» (1920 × 1080). Скачивать папку нужно, только если хотите
держать всё у себя.

## Как поставить у себя за три шага

1. **Возьмите папку** `sea-battle-chat` целиком (в ней `index.html`, `builder.html`
   и папка `js`). Можно положить рядом с другими нашими программами или открыть
   как локальный файл — интернет нужен только для чата.
2. **Соберите ссылку:** откройте `builder.html` в браузере, впишите имя канала
   Twitch (можно вставить ссылку вида `twitch.tv/имя`), поправьте настройки под
   свой кадр — предпросмотр справа уже показывает игру без чата. Нажмите
   «Скопировать ссылку».
3. **Добавьте в OBS:** «Источники» → «+» → «Браузер», вставьте ссылку, ширина
   1920, высота 1080, галочка «Выключить источник, когда он не виден» — по вкусу.
   Фон у страницы прозрачный: море занимает нижнюю часть кадра, остальное можно
   накладывать на любую сцену.

Хотите, чтобы «Светлячки» и бой жили в одном источнике — в конструкторе включите
раздел «Вместе со Светлячками» и скопируйте ссылку на `stage.html`; в OBS тогда
нужен только один источник «Браузер».

Хотите проверить без зрителей — добавьте к ссылке `demo=1`: восемь придуманных
ботов сами пишут команды каждые 1–3 секунды.

## Один источник: «Светлячки» + «Морской бой»

Чтобы в OBS был не десяток источников, а один, есть `stage.html` — общая сцена.
Внутри неё два прозрачных слоя на весь кадр: «Светлячки» (они уже опубликованы,
их страница берётся по адресу по умолчанию) и «Морской бой» (`index.html` рядом).
Сцена сама читает чат и переключает слои:

* обычно видно «Светлячков», бой ждёт в невидимом слое (корабли зрителей при
  этом уже появляются — мир живёт, просто не рисует кадры);
* кто-то пишет боевую команду (`!огонь`, `!играть`, `!fire`, `!join` и другие
  команды боя) — «Светлячки» плавно гаснут за 1,5 секунды и появляется море;
* если боевых команд нет `battle_idle` минут (по умолчанию 3), сцена возвращает
  «Светлячков»; после включения боя он держится минимум 30 секунд, чтобы
  картинка не дёргалась;
* стример и модераторы могут переключить вручную: `!бой` — включить бой сейчас,
  `!светлячки` — вернуть «Светлячков» (автозапуск от этого не выключается);
* `auto=0` — без автозапуска, переключают только `!бой` и `!светлячки`.

Как включить: в конструкторе откройте раздел «Вместе со Светлячками», поставьте
галочку, при желании поменяйте тему и подложку неба «Светлячков» (или вставьте
свою готовую ссылку в поле ссылки) и скопируйте ссылку на `stage.html`. В OBS
добавьте **один** источник «Браузер» с этой ссылкой — больше ничего не нужно.

Параметры сцены (добавляются к обычным настройкам боя):

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `auto` | `1` | включать бой по командам чата (`0` — только `!бой`) |
| `battle_idle` | `3` | сколько минут без боевых команд держать бой |
| `svet_url` | наша опубликованная страница «Светлячков» | своя ссылка «Светлячков» (можно вставить готовую — параметры передаются как есть) |
| `svet_theme` | — | тема «Светлячков»: `city`, `meadow`, `space`, `none` |
| `svet_backdrop` | `0` | подложка неба «Светлячков», % (0–80) |

## Команды

Пишутся в чат канала. Русские и латинские названия равнозначны, регистр любой.
У каждой команды своя пауза на каждого зрителя — спамить бесполезно, в паузе
команда молча игнорируется. Знаки препинания после команды не мешают:
`!огонь!`, `!щит.` и `!огонь, Вася` работают как `!огонь`, `!щит` и `!огонь Вася`.

| Команда | Что делает |
|---|---|
| `!огонь` | выстрел по ближайшему кораблю (ядро летит дугой) |
| `!огонь ник` | выстрел по конкретному кораблю (если не найден — по ближайшему) |
| `!вперёд` / `!назад` | сдвинуться по воде вправо / влево (`!right` / `!left`) |
| `!щит` | щит на 5 секунд, поглощает одно попадание; пауза 20 секунд |
| `!ремонт` | +1 прочность, не выше трёх; пауза 30 секунд |
| `!играть` / `!уйти` | войти в игру / уплыть за край (`!join` / `!leave`) |

Команды стримера и модераторов (работают только у broadcaster и moderator):

| Команда | Что делает |
|---|---|
| `!раунд` | начать новый раунд прямо сейчас |
| `!пауза` / `!продолжить` | заморозить / разморозить игру |
| `!очистить` | убрать все корабли с воды |

## Как идёт раунд

Корабль появляется при первом сообщении зрителя (или по `!играть`, если в
настройках выбран вход по команде). Над кораблём виден ник и три сердечка
прочности. Когда прочность кончается, корабль тонет за две секунды и ждёт
следующего раунда — его ник серым висит внизу, «на дне». Когда на воде остался
один корабль, он получает корону, в кадре появляется «Победитель раунда: ник», а
в таблице «Лучшие капитаны» прибавляется победа. Через несколько секунд все
корабли снова всплывают с тремя сердечками — начинается новый раунд.

Больше `max_ships` кораблей на воду не выходит: остальные ждут в очереди, в кадре
видно «+N в очереди». Освободилось место — заходит следующий. Зритель, который
молчит дольше `idle_minutes`, уплывает за край.

## Настройки

Все настройки живут в адресе страницы — их собирает конструктор. Можно править
ссылку руками.

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `channel` | — | канал Twitch (можно ссылку `twitch.tv/ник`) |
| `theme` | `sea` | `sea` — вода с волнами, `none` — только корабли |
| `sea_height` | `30` | высота полосы моря, % кадра (15–60) |
| `ship_scale` | `1` | размер кораблей (0.6–2) |
| `max_ships` | `30` | сколько кораблей на воде (5–60) |
| `join` | `chat` | `chat` — входит любое сообщение, `command` — только `!играть` |
| `cooldown` | `6` | пауза команд зрителя, секунд (2–30) |
| `idle_minutes` | `5` | через сколько минут молчания корабль уплывает |
| `round_pause` | `10` | пауза между раундами, секунд |
| `leaderboard` | `1` | показывать таблицу лучших (`0` — выключить) |
| `lang` | `ru` | язык надписей: `ru` или `en` |
| `demo` | `0` | боты вместо чата (`1` — включить) |

Пример ссылки: `index.html?channel=имя&theme=none&sea_height=25&max_ships=20`.
Значения по умолчанию в ссылку не пишутся.

## Частые вопросы

**Тихий чат — это не обрыв.** Если в канале никто не пишет, картинка просто ждёт;
страница сама проверяет связь и переподключается, если Twitch перестал отвечать.

**Ник с матом.** Ники показываются как есть, но если в нике есть мат из нашего
списка, видна только первая буква, остальное закрыто звёздочками.

**Прозрачность.** Фон вне полосы моря прозрачный. Если в OBS видна тёмная
подложка — проверьте, что в источнике «Браузер» не включён «Пользовательский
CSS» и что ссылка открыта на `index.html`, а не на `builder.html`.

## Чего не умеет

- не входит в Twitch и не отправляет сообщения в чат — только читает открытый чат;
- не хранит ничего на сервере: счёт побед лежит в памяти браузера OBS
  (`localStorage`, ключ по каналу) и может пропасть при чистке кэша;
- нет шторма, кракена и звуков — этого в задании этой версии нет;
- не меняет «Светлячков»: они берутся по своей ссылке как есть, поэтому их
  обновления подхватываются сами;
- не работает без интернета для чата (демо-режим работает и без сети).

## Проверить самому

В папке проекта, если установлен Node.js (пакеты не нужны):

```
node --test --test-isolation=none "tests/*.test.js"
```

Здесь 415 тестов: команды и паузы, права модераторов, урон/щит/ремонт/
потопление, раунды и победитель, очередь и лимит кораблей, раскладка по рядам и
непересекающиеся подписи, метки выстрела, демо-боты, ссылка ⇄ настройки, цвет
ника, маска мата, физика с подставными часами, сто кадров на поддельном холсте,
анонимность сокета и переключение слоёв на общей сцене.
