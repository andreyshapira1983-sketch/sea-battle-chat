Морской бой чата

Соберите ссылку для OBS

Настройте игру, посмотрите живой предпросмотр и вставьте готовую ссылку в источник «Браузер» в OBS. Ничего устанавливать не нужно: страница работает прямо в браузере, а всё остальное рисуется кодом. Хотите «Светлячков» и «Морской бой» в одном источнике? Включите раздел «Вместе со Светлячками» внизу.

Настройки

Впишите имя, @имя или ссылку twitch.tv/имя — логин возьмём из неё.

Тема

«Море» — полупрозрачная вода с волнами, «без моря» — только корабли.

Сколько процентов кадра занимает полоса воды. Остальное — прозрачно.

1 — обычный, 2 — крупные корабли, 0,6 — маленькие.

Сколько кораблей помещается на воде. Остальные зрители ждут в очереди.

Когда появляется корабль

«Любое сообщение» — корабль появляется от первого сообщения зрителя.

Сколько секунд зритель ждёт между своими командами.

Если зритель молчит, его корабль уплывает — освобождается место.

Через сколько секунд после победы начинается новый раунд.

Живой предпросмотр

демо

Шахматка показывает прозрачность: в OBS фон вне моря будет прозрачным. Здесь играют придуманные зрители, в OBS будут сообщения вашего чата.

Ссылка для OBS

Открыть

Тема «море», море 30%, до 30 кораблей, вход: любое сообщение, русский.

  1. OBS → «Источники» → «+» → «Браузер».
  2. Вставьте ссылку в поле «URL».
  3. Ширина 1920, высота 1080 → «ОК».

Вместе со Светлячками

В OBS нужен ОДИН источник «Браузер»: страница сама покажет «Светлячков», а по командам боя плавно переключится на море. Без этой галочки ссылка выше — только «Морской бой».

Сюда можно вставить готовую ссылку «Светлячков» целиком. Пустое поле — адрес по умолчанию.

Тема их конструктора; «по умолчанию» — оставить как есть.

0 % — прозрачно, видно только светлячков.

Команда боя от зрителя сама включает море. Выключите — бой будет включать только стример командой !бой.

Сколько минут без команд боя — и сцена сама вернёт «Светлячков».

Открыть

Море, «Светлячки» и автопереключение — один источник для OBS.

Одиночная ссылка выше остаётся для случая «только бой, без Светлячков».
